01 · Probability as evidence

Naive Bayes

A prior belief meets evidence. “Naive” means features vote independently once the class is known—not that the method is foolish.

CORE IDEA

Turn the question around

We want P(class | evidence), but usually know how common the class is and how likely the evidence is within it.

P(C | x₁…xₙ) ∝P(C)×∏ P(xᵢ | C)

Intuition: prior × evidence votes. Normalize the scores across classes only at the end.

Why the independence assumption?

It replaces a huge joint probability table with one small likelihood per feature and class. Correlated evidence can be double-counted, but the ranking can still be remarkably useful.

Zero counts and Laplace smoothing

An unseen feature would multiply the score by zero. Add-α smoothing uses (count + α) / (class count + α × vocabulary size) so absence of history is not impossibility.

03 · Change has a direction

Derivatives → gradient descent

A derivative is a local sensitivity: how much output changes after a tiny input nudge. A gradient collects one sensitivity per parameter.

FROM SECANT TO TANGENT

Zoom into change

average slope = [f(x+h)−f(x)] / hf′(x) = limh→0 [f(x+h)−f(x)] / h

As h shrinks, the secant line through two points becomes the tangent line at one point. Its slope predicts nearby change: f(x+Δx) ≈ f(x)+f′(x)Δx.

Contour-map intuitionThe gradient points steepest uphill. To minimize loss, walk the opposite way.
θ ← θ − η∇L(θ)

η is the learning rate: step size, not direction.

04 · Local effects compose

Chain rule → backpropagation

A neuron is a chain of small functions. Backprop walks that chain backward, multiplying local derivatives to assign each parameter its share of the error.

CHAIN RULE

Follow every path

Suppose x → z → ŷ → L. A change in x affects loss through every link:

∂L/∂x = ∂L/∂ŷ · ∂ŷ/∂z · ∂z/∂xupstream gradient × local derivative
  1. Forward: cache each intermediate value.
  2. Backward: start with ∂L/∂L = 1.
  3. Multiply: pass gradients through each local operation.
  4. Update: nudge each weight opposite its gradient.

Deep intuition: backprop is dynamic programming for derivatives—reuse partial results instead of expanding one enormous symbolic expression.

Interview field guide

Explain it without hiding behind notation.

Try each question aloud before revealing the answer. Strong answers give the intuition, equation, assumption, and one practical consequence.

01When can Naive Bayes work despite correlated features?

Classification needs the correct score ordering, not perfectly calibrated probabilities. Correlation can distort posterior confidence yet leave the decision boundary useful. Mention double-counting evidence and checking calibration.

02Accuracy is 99%. Why might the model be useless?

With 1% positives, predicting negative always gets 99% accuracy and zero recall. Ask for the confusion matrix, base rate, precision-recall curve, and error costs.

03ROC-AUC or PR-AUC for rare positives?

Usually PR-AUC: it focuses on positive-class retrieval and exposes false-positive burden. ROC-AUC can look strong because the large negative class makes a low FPR easy. State prevalence and the decision objective.

04What does a derivative mean beyond “slope”?

It is local sensitivity: units of output change per unit of input change. In optimization it predicts the first-order effect of nudging a parameter.

05What happens if the learning rate is too large?

Steps can overshoot the minimum, oscillate, or diverge. Too small converges slowly or stalls on flat regions. Schedules and adaptive optimizers modify effective step sizes.

06What causes vanishing gradients?

Backprop multiplies many local derivatives. If most magnitudes are below one, the product shrinks exponentially, so early layers learn slowly. ReLU-family activations, residual paths, normalization, and careful initialization help.

07Is a 0.5 classification threshold special?

Only under particular assumptions about calibrated probabilities and symmetric costs. Choose a threshold on validation data using operating constraints or expected cost, then test it on untouched data.

08How would you gradient-check backprop?

Compare the analytic gradient to a centered finite difference: [L(w+ε)−L(w−ε)]/(2ε). Use a small ε and relative error, while accounting for numerical precision and nondifferentiable points.
